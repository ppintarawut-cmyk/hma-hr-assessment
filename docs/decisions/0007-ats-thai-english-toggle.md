# ปุ่มสลับภาษาไทย / อังกฤษใน ATS — แปลเฉพาะหน้าจอ ไม่แปลข้อมูล

ATS ต้องใช้ได้กับผู้ใช้ที่อ่านภาษาอังกฤษ จึงเพิ่มปุ่ม 🌐 EN / ไทย ที่แถบบน โดยยึดพฤติกรรมเดียวกับ hma-testing-system:
เก็บค่าใน localStorage คีย์ `hma_lang` ค่า `'th'`/`'en'` (สลับที่ระบบไหนก็จำค่าเดียวกันเมื่ออยู่ origin เดียวกัน)
ปุ่มแสดงภาษาที่จะสลับไป และภาษาไทยเป็นค่าเริ่มต้น

ต่างจากระบบสอบตรงที่พจนานุกรม `EN` ใช้ **ข้อความไทยต้นฉบับเป็นคีย์** แทนคีย์ตั้งชื่อ เพราะ record ผู้สมัคร
เก็บข้อความไทยไว้แล้วบางส่วน (คำเตือนจากการสแกน, ที่มาของคะแนน) — `tStored()` แปลตอนแสดงผลได้ทันที
(ข้อความที่มีตัวเลขแทรกใช้ `EN_PATTERNS`) โดยไม่ต้อง migrate ข้อมูล และโค้ดยังอ่านเป็นภาษาไทยเหมือนเดิม
ข้อความคงที่ใน HTML ไม่ต้องติด attribute: `captureStaticI18n()` จดต้นฉบับไว้ครั้งเดียวก่อน render แรก
ข้อความไทยที่ไม่มีคำแปลแสดงเป็นไทยตามเดิมและถูกจดใน `I18N_MISSING` — เทสต์เดินทุกหน้าจอในโหมดอังกฤษแล้วตรวจว่าว่าง

**ไม่แปลข้อมูล**: resume, ชื่อทักษะ (คลังคำต้องจับภาษาไทยใน resume ได้เสมอ), เทมเพลตอีเมลและหัวข้อประเมิน
ที่บันทึกแล้ว — สิ่งที่ผู้ใช้พิมพ์/บันทึกคงเป็นภาษาที่บันทึก ค่าเริ่มต้นของ DB ใหม่ (หรือกด "คืนค่าเริ่มต้น")
ใช้ภาษาที่เปิดอยู่ตอนนั้น · ภาษาไม่มีผลกับการคิดคะแนนหรือการตรวจจับ AI

ทางเลือกที่ปัดตก: คีย์ตั้งชื่อแบบระบบสอบ (ต้อง migrate ข้อความไทยที่เก็บใน record), ติด data-i18n ทุก element
(แก้ HTML เกือบร้อยจุด), แปลข้อมูลผู้ใช้อัตโนมัติ (เปลี่ยนสิ่งที่ผู้ใช้บันทึกไว้โดยไม่ได้ขอ)
