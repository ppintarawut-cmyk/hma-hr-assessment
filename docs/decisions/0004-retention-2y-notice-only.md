# เก็บข้อมูลผู้สมัคร 2 ปี — ระบบแจ้งเตือนเมื่อเกิน แต่ไม่ลบอัตโนมัติ

นโยบาย retention ของข้อมูลผู้สมัครใน ATS (รวมข้อความ resume): เก็บ 2 ปีนับจากวันที่เคสปิด
(สถานะ Hired หรือ Rejected) เมื่อมีรายการเกินกำหนด ระบบเพียงแสดงข้อความแจ้งว่ามีข้อมูล
เกินอายุกี่รายการ — การลบเป็นการตัดสินใจของ HR ล้วน ๆ (ลบ manual รายคน)

เหตุผลที่ไม่ลบอัตโนมัติ: ระบบผู้ใช้คนเดียว การลบเงียบ ๆ ที่คาดไม่ถึงอันตรายกว่าการเก็บเกิน
และการลบจริงต้องครอบคลุมไฟล์ backup (OneDrive) กับ CSV ที่เคย export ด้วย
ซึ่งอยู่นอกการควบคุมของแอป — จึงให้มนุษย์เป็นคนปิด loop
