# ATS เป็นระบบผู้ใช้คนเดียว เก็บข้อมูลในเครื่อง (localStorage) โดยตั้งใจ

HMA ATS (hma-ats.html) มีผู้ใช้จริงคนเดียวคือ HR ที่ดูแลการสรรหา จึงเลือกเก็บข้อมูลผู้สมัครทั้งหมดใน
localStorage ของ browser เครื่องเดียว ไม่มี backend/auth — แลกกับความง่ายในการ deploy
(ไฟล์ HTML ไฟล์เดียว ไม่ต้องมี server) และข้อมูลส่วนบุคคลผู้สมัครไม่ออกไปนอกเครื่อง
ถ้าในอนาคตต้องแชร์ข้อมูลข้ามทีม ให้ถือเป็นการตัดสินใจสถาปัตยกรรมใหม่ (backend/SharePoint)
ไม่ใช่การส่งไฟล์ export ไปมาแทน database
