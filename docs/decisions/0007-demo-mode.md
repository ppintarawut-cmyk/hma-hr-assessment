# โหมดทดสอบเป็นสวิตช์ที่ URL ไม่ใช่ไฟล์แยก

ทดลองใช้งานหรือสอนคนใหม่ต้องทำได้โดยไม่แตะข้อมูลผู้สมัครจริง เปิดด้วย `hma-ats.html?demo=1`
แล้วแอปจะตัดขาดจากข้อมูลจริงทั้งสามทางที่มันเข้า/ออก

- **localStorage** เก็บคนละ key (`hma_ats_demo`) — เพิ่ม/ลบ/แก้อะไรก็ไม่กระทบของจริง
- **สำรองอัตโนมัติ** ปิด ไม่อ่าน handle ที่เก็บไว้ด้วยซ้ำ — ไม่มี handle ก็ไม่มีทางเขียนทับ
  ไฟล์ backup จริงใน OneDrive (ยังกดดาวน์โหลด JSON เองได้)
- **ผลสอบจาก Firestore** ไม่ดึง เพราะเป็นข้อมูลบุคคลจริงของระบบสอบ

เหตุผลที่ไม่ทำเป็นไฟล์ `hma-ats-demo.html` แยก: แอปนี้เป็นไฟล์เดียวที่แจกจ่ายด้วยการ
ก๊อปปี้ ถ้าแยกไฟล์จะมีสองสำเนาที่ต้องแก้ให้ตรงกันตลอดไป และสำเนาทดสอบจะค่อย ๆ
ล้าสมัยจนทดสอบแล้วไม่ตรงกับของจริง — สวิตช์ที่ URL ทำให้โค้ดที่ทดสอบคือโค้ดตัวเดียวกันเป๊ะ

เหตุผลที่ต้องมีแถบเตือนค้างบนจอและเปลี่ยนชื่อแท็บเบราว์เซอร์: ความเสี่ยงที่แท้จริงของ
โหมดทดสอบไม่ใช่ข้อมูลทดสอบรั่วไปปนของจริง แต่คือคนทำงานจริงอยู่ในโหมดทดสอบโดยไม่รู้ตัว
แล้วนึกว่าบันทึกผู้สมัครไปแล้ว ทั้งที่ข้อมูลอยู่คนละที่
