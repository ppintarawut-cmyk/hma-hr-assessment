# ไฟล์ตัวอย่างสำหรับทดสอบ

ทุกไฟล์ในโฟลเดอร์นี้เป็น **ข้อมูลสมมติทั้งหมด** — ชื่อ อีเมล เบอร์โทร บริษัท สถาบัน
ไม่มีของบุคคลจริง อีเมลใช้โดเมน `example.com` และเบอร์เป็นรูปแบบทดสอบ (`08x-000-000x`)
ใช้ทดสอบ Resume Scanner และการนำเข้า JD ได้โดยไม่ต้องแตะข้อมูลผู้สมัครจริง

## ใช้คู่กับโหมดทดสอบ

เปิดแอปด้วย `hma-ats.html?demo=1` ก่อนทดสอบเสมอ โหมดนี้เก็บข้อมูลคนละที่กับของจริง
ปิดสำรองอัตโนมัติ และไม่ดึงผลสอบจาก cloud (ดู `docs/decisions/0007`)

## ไฟล์และสิ่งที่แต่ละไฟล์ใช้ทดสอบ

| ไฟล์ | ทดสอบอะไร | ผลที่ควรได้ |
|---|---|---|
| `resume-01-single-column.pdf` | resume ทั่วไป ชื่อตัวโตบนสุด แถวติดต่อคั่นด้วย `\|` | สมชาย ใจดี · somchai.jaidee@example.com · 081-000-0001 |
| `resume-02-two-column.pdf` | ชื่อ/ติดต่ออยู่แถบซ้าย เนื้อหาอยู่ขวา — ทรงที่อ่านชื่อผิดได้ง่าย | PLOY BOONMEE · ploy.b@example.com · 082-000-0002 |
| `resume-03-scanned-image.pdf` | หน้าเป็นภาพล้วน ไม่มีชั้นข้อความ — บังคับใช้ OCR | NARONG SAETANG · narong.s@example.com (ติด badge 🔍 อ่านด้วย OCR) |
| `jd-01-production-engineer.pdf` | นำเข้า JD จาก PDF ภาษาไทย | วิศวกรฝ่ายผลิต · Production Engineering · 3 ปี · ทักษะ ~12 รายการ |
| `jd-02-manpower-plan.xlsx` | นำเข้า JD จาก Excel — แผ่นแรกเป็นฟอร์ม แผ่นสองเป็นตาราง 3 ตำแหน่ง | ถามยืนยันแล้วนำเข้า Sales Engineer / HR Officer / ช่างซ่อมบำรุง |

`resume-03` ต้องเปิดสวิตช์ OCR ที่แท็บ Resume Scanner และครั้งแรกจะโหลดชุดข้อมูลภาษา
ประมาณ 15 MB จาก CDN ใช้เวลาสักพัก

## สร้างใหม่

ไฟล์ชุดนี้สร้างด้วยสคริปต์ (pdfkit + node-canvas + SheetJS) ไม่ได้แก้ด้วยมือ
ถ้าต้องปรับเนื้อหาให้แก้ที่สคริปต์แล้วสร้างใหม่ทั้งชุด เพื่อให้ผลลัพธ์ทำซ้ำได้
